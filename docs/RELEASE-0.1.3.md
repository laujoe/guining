# 归宁 0.1.3 · 非商业源码公开试玩

整理日期：2026-10-20。

## 本次变化

- 明确禁止未经授权的商业使用：自有代码 PolyForm Noncommercial 1.0.0，自有内容 CC BY-NC-SA 4.0；保留第三方许可。
- 整理独立源码快照、README、贡献指南、素材说明、反馈模板和 GitHub Actions 测试配置。
- 去除公开包中的本机绝对路径、开发插件、旧导出和原始附件；字体统一为附完整 OFL 许可的霞鹜文楷。
- 主菜单加入“许可与来源”，APK 内可离线查看项目署名、字体、音乐与引擎许可。
- 加入 Android 横屏导出与多指触屏操作：批阵移动与挥笔组合、迷宫行走与转向组合、顶风与跳跃组合；暂停时清理按住状态并阻止底层触控抢走弹窗输入。
- 提供 Windows ZIP、当前用户安装器及 Android 测试 APK；保留旧版 schema 1 存档。
